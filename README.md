# Smart Lighting Embedded System

Smart lighting system with automatic light regulation using Raspberry Pi,
Raspberry Pi Pico, light sensors, PWM and Wi-Fi communication.

## Overview

The system automatically adjusts lighting intensity based on ambient light
conditions while also allowing manual control through a mobile application.

## Features

- Automatic light intensity regulation
- PWM-based dimming control
- Ambient light measurement
- Raspberry Pi and Raspberry Pi Pico integration
- Wi-Fi communication
- Mobile application control
- UART and I²C communication

## Hardware

- Raspberry Pi
